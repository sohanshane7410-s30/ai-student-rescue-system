# AI Student Rescue System 🎓

A Python-based student performance analysis tool that identifies learning gaps, prioritizes students for academic support, and recommends targeted interventions.

## 🎯 Project Objective

Help educators identify students who may need additional support and make data-informed decisions about the next learning intervention.

## ✨ Features

- **Student Performance Analysis:** Tracks previous and current mastery scores.
- **Learning Gap Detection:** Calculates each student's gap from the 80% mastery target.
- **Risk Classification:** Categorizes students as critical, high risk, monitoring, or on track.
- **Rescue Priority:** Helps educators identify students who may need attention first.
- **Personalized Interventions:** Recommends targeted practice, diagnostic review, or enrichment.
- **Progress Tracking:** Calculates changes in mastery scores.

## 🛠️ Technologies

- Python
- Pandas
- Rule-based data analysis

## ⚙️ How It Works

1. Loads student mastery data.
2. Calculates progress and gaps from the target.
3. Classifies students according to configurable rules.
4. Prioritizes students for follow-up.
5. Recommends a potential next intervention.

## ⚠️ Limitations

This is a portfolio prototype using sample data and rule-based recommendations. Its recommendations require educator review; the project does not independently diagnose learning difficulties or establish that an intervention caused an improvement.
